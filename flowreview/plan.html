FlowReview — what gets built, in what order

One Go binary with its own WKWebView window. Tree-sitter structure for every language, exact Go semantics in-process, Go toolchain downloaded on demand. llama-server embedded in the binary. GitHub through the gh token. Full text: PLAN.md.
